# Advanced

Tools for screening workflows. Each one is a single undo step, so you can try one and press ++ctrl+z++ if you don't like the result.

<div class="grid cards" markdown>

- :material-chart-bell-curve: **[Serial dilution](serial-dilution.md)**: dose series across rows or columns
- :material-target: **[Distributing controls](controls.md)**: spread controls evenly to catch positional effects
- :material-shuffle-variant: **[Randomizing layouts](randomization.md)**: reproducible, seeded shuffles
- :material-content-copy: **[Replicate plates](replicate-plates.md)**: copies, optionally randomized
- :material-view-grid-plus: **[4 × 96 → 384](384-well.md)**: quadrant interleave with traceability
- :material-auto-fix: **[Auto-fill fields](auto-fill.md)**: vehicle and class follow the compound
- :material-file-delimited: **[Platemap export](platemap-export.md)**: pycytominer-ready CSVs
- :material-image: **[Figure export](figure-export.md)**: vector PDF/SVG, PNG up to 1200 dpi

</div>
