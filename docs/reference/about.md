# About & license

**PlateMap Studio** is developed at **LIVR, Vrije Universiteit Brussel** for high-content screening and Cell Painting experiments.

- Source code: [github.com/LIVR-VUB/Platemap-studio](https://github.com/LIVR-VUB/Platemap-studio)
- Downloads: [Releases](https://github.com/LIVR-VUB/Platemap-studio/releases/latest)

## Built with

Electron · React · TypeScript · Vite · immer. Documentation built with MkDocs Material.

## Contributing

Pull requests are welcome. Before opening one, run `npm run build`; it must pass the type-check. The docs live in the `docs/` folder of the repository: every page has an ✏️ edit button at the top that takes you straight to its source.
