# Keyboard shortcuts

On macOS, use ++cmd++ wherever ++ctrl++ is shown.

## Tools

| Keys | Action |
|---|---|
| ++v++ | Select tool |
| ++b++ | Brush |
| ++e++ | Eraser |

## Editing

| Keys | Action |
|---|---|
| ++ctrl+z++ | Undo |
| ++ctrl+shift+z++ / ++ctrl+y++ | Redo |
| ++ctrl+c++ | Copy selected wells |
| ++ctrl+v++ | Paste at the top-left selected well |
| ++delete++ / ++backspace++ | Clear selected wells |
| ++enter++ | Apply the value typed in the Inspector |
| ++esc++ | Cancel typing, or deselect |

## Selection

| Keys | Action |
|---|---|
| ++ctrl+a++ | Select all wells |
| ++ctrl+d++ | Deselect |
| ++shift++ + click / drag | Add to selection |
| ++ctrl++ + click / drag | Toggle wells |

## Files & export

| Keys | Action |
|---|---|
| ++ctrl+n++ | New project (choose format) |
| ++ctrl+o++ | Open project |
| ++ctrl+s++ | Save project |
| ++ctrl+shift+s++ | Save project as |
| ++ctrl+e++ | Export figure |
| ++ctrl+shift+e++ | Export platemap CSV |

## View

| Keys | Action |
|---|---|
| ++ctrl++ + mouse wheel | Zoom |
| ++ctrl+equal++ / ++ctrl+minus++ | Zoom in / out |
| ++ctrl+1++ | Actual size (100 %) |

**Help → Keyboard shortcuts** shows this list inside the app.
