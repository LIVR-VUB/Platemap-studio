# Changelog

Downloads for every version: [Releases](https://github.com/LIVR-VUB/Platemap-studio/releases).

## 0.1.2

- **Concentration units:** fM–M, pg/ml–g/l, %, % v/v, % w/v, ppm, ppb, U/ml, IU/ml, fold, MOI, plus cell, time and volume units
- Unit dropdowns in the Inspector, Serial dilution, field settings and brush
- Fields panel lists numbers per value + unit; edit value and unit everywhere at once
- Changing a field's default unit keeps the meaning of existing values
- Figure labels show per-well units; legend reports "mixed units"

## 0.1.1

- macOS builds are signed, fixing *"app is damaged"* on Apple Silicon
- "First launch on macOS" instructions

## 0.1.0

First release.

- 6–1536-well and custom formats, multi-plate projects, start screen
- Inspector, brush, eraser, copy/paste, quick selections
- Unlimited undo with History panel; autosave
- Custom fields, colors, colorblind-safe palettes, layers
- Serial dilution, distribute controls, seeded randomization, replicate plates, 4 × 96 → 384
- Checks panel
- PDF / SVG / PNG figure export
- pycytominer platemap + `barcode_platemap.csv` export with auto-filled vehicle/class/group
- Installers for Windows, macOS and Linux
